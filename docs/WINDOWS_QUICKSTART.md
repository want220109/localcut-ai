# Windows PC에서 무료로 빌드하고 테스트하기

## 설정 파일 인코딩 오류 뒤 이어서 진행

사용자 PC 로그에서 `.exe` 제작 뒤 `Invalid object passed in` 오류가 확인되었습니다. Windows PowerShell 5.1이 한국어 UTF-8 `package.json`을 기본 ANSI 문자셋으로 읽은 실행기 오류입니다. 새 버전은 UTF-8을 명시합니다.

수정 ZIP의 **CONTINUE-WINDOWS-TEST.cmd**와 **scripts 폴더**를 기존 **LocalCut-AI 폴더**에 복사하고 같은 이름의 파일을 덮어쓰세요. 기존 `release`, `.venv-win`, `node_modules` 폴더는 그대로 둡니다. 이어서 `CONTINUE-WINDOWS-TEST.cmd`를 더블클릭하면 이미 만든 설치 파일을 찾아 설치·설치된 앱 테스트부터 진행합니다. `package.json` 옆에서 실행해야 합니다. 수정 ZIP을 새로운 빈 폴더에만 압축 풀어 실행하면 기존 설치 파일이 없어 중단됩니다.

이전 결과 JSON은 백업하고, 새 결과에는 `RESUME_INSTALL_ONLY` 모드와 이번 실행 단계만 기록합니다. 성공 시 `INSTALLED_APP_TEST_PASSED`로 표시하며 앞선 빌드·소스 테스트를 이번에 다시 실행한 것으로 기록하지 않습니다. 실제 한국어 음성인식과 온라인 업데이트는 별도 검증입니다.

## 처음 실행하는 경우

이 채팅의 작업 환경은 클라우드 Linux입니다. PC에서 채팅을 열었다는 것만으로 Windows 파일·화면·터미널을 직접 제어할 수는 없습니다. 아래 실행기를 PC에서 한 번 실행하면 나머지 기술 검증을 자동으로 진행합니다. **실행기 자체는 아직 Windows에서 검증하지 않았으며, 실행 결과를 받아 오류를 수정하는 단계입니다.**

1. 제공한 **Windows 테스트용 소스 ZIP**을 PC에 저장합니다.
2. ZIP을 우클릭하여 **모두 압축 풀기**를 선택합니다. 압축 안에서 바로 실행하면 안 됩니다. 로컬 드라이브에 압축을 푸세요.
3. 폴더 안의 **START-WINDOWS-TEST.cmd**를 더블클릭합니다.
4. Python 3.12 또는 Node.js가 없으면 무료 도구 설치 여부를 묻습니다. `Y`를 입력하면 Windows Package Manager로 설치합니다. 관리자 승인창이 표시될 수 있습니다. 도구와 의존성을 내려받으므로 인터넷과 6 GB 이상의 여유 공간이 필요합니다.
5. 검증 중에는 명령창을 닫거나 자동으로 열리는 테스트 창을 조작하지 마세요. 종료할 기존 LocalCut 작업이 있으면 먼저 직접 마쳐 주세요. 실행기는 편집 중인 앱을 강제로 종료하지 않습니다.

실행기는 프로젝트 안에 별도 Python 환경을 만들고, 고정된 의존성·FFmpeg를 받습니다. 이어서 엔진·UI 테스트 → Windows용 Python 런타임 묶기 → `.exe` 설치 파일 제작 → 현재 Windows 사용자 계정에 설치 → **설치된 앱에서 편집·MP4 출력·종료·재실행 테스트**를 수행합니다. 성공한 뒤 일반 프로그램 화면을 엽니다. GitHub 계정, 클라우드 빌드 결제, 유료 API, 코드 서명 인증서를 사용하지 않으며 외부에 릴리스를 게시하지 않습니다.

Windows가 실행을 차단하면 경고 내용부터 확인해 주세요. Defender·SmartScreen·조직 보안 정책을 끄지 마세요. 회사 PC의 설치 제한은 관리자 정책을 따라야 합니다. `.cmd`는 동봉한 PowerShell 실행기를 **현재 프로세스에서만** 실행하도록 호출하며 컴퓨터의 영구 실행 정책을 바꾸지 않습니다.

## 성공 또는 실패 확인

- **windows-results/RESULT.txt**: 완료한 단계와 실패 이유. 이 내용을 채팅에 붙여 넣으면 이어서 진단할 수 있습니다. 영상 파일이나 전체 사용자 데이터 폴더는 보낼 필요가 없습니다.
- **windows-results/result.json**: 실제 실행한 단계·종료 코드의 기록. 실패하면 성공으로 표시하지 않습니다.
- **windows-results/** 아래 로그: 각 설치·빌드·검증 명령의 출력.
- 성공한 경우 **release/LocalCut-AI-0.1.0-x64-Setup.exe**: 이후 다른 Windows PC에 설치할 수 있는 로컬 시험용 설치본. 이 파일이 이미 ZIP에 들어 있다는 뜻은 아닙니다.
- **windows-results/installer-sha256.txt**: 방금 생성한 설치 파일의 체크섬.

코드 서명을 구매하지 않은 시험본이므로 Windows 게시자 경고가 나타날 수 있습니다. 설치본 공개 배포 전에는 기존 RELEASE/THIRD_PARTY 문서의 서명·라이선스·관리자 승인 절차를 검토해야 합니다.

## 실제 한국어 영상 테스트

자동 시험은 합성 패턴·톤/무음 영상으로 기술 동작을 확인합니다. **실제 한국어 인식 정확도와 의미 보존을 확인한 결과는 아닙니다.**

1. 일반 프로그램 화면에서 **모델 · 업데이트**를 엽니다.
2. `small`(약 490 MB, 한국어 권장) 또는 `tiny`(약 76 MB, 속도 우선)를 선택합니다.
3. **다운로드에 동의하고 설치**를 누릅니다. 모델 파일만 받으며 원본 영상과 대본은 외부에 전송하지 않습니다.
4. 먼저 30초~2분 정도의 짧은 한국어 대화 영상을 불러옵니다.
5. **AI 분석·편집점 생성** → 대본·보존/삭제 구간 확인 → **MP4 출력**을 진행합니다.
6. 편집본을 재생해 실제 음성과 자막, 중요 문장 보존을 확인합니다. 앱을 종료·다시 실행해 최근 작업도 열어 봅니다.

다운로드 차단, 인식 실패 또는 영상 출력 실패가 나타나면 표시된 오류 문구를 채팅에 알려 주세요. 온라인 업데이트는 실제 승인된 릴리스가 연결되어야 별도로 시험할 수 있으며, 이 실행기는 업데이트 성공으로 보고하지 않습니다.
