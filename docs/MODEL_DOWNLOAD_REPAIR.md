# 한국어 모델 다운로드 404 복구

사용자 화면에서 small 모델의 `vocabulary.json` 요청이 Hugging Face 404로 실패한 것을 확인했습니다. 기존 코드가 어휘 파일 이름을 JSON으로 고정한 오류입니다. 모델이 게시한 고정 버전의 파일 목록을 먼저 확인하고 `vocabulary.txt`와 `vocabulary.json` 모두 지원하도록 수정했습니다.

## 이미 설치된 0.1.0 프로그램에서 복구하기

설치 프로그램 전체를 다시 빌드할 필요가 없습니다.

1. **LocalCut AI를 정상 종료**합니다. 편집 중이라면 작업을 먼저 마칩니다.
2. 복구 ZIP의 압축을 풀어 **REPAIR-KOREAN-MODEL.cmd 파일, models 폴더, scripts 폴더**를 이전 빌드에 사용한 **기존 LocalCut-AI 폴더**에 복사합니다. 같은 이름의 소스 파일은 덮어씁니다. `.venv-win`, `node_modules`, `release`는 지우지 않습니다.
3. 기존 폴더에서 **REPAIR-KOREAN-MODEL.cmd**를 더블클릭합니다. 이전에 동의한 `small` 모델의 다운로드를 복구합니다. 기존 다운로드 캐시를 재사용하고 없는 모델 파일만 받습니다.
4. 성공 메시지가 나오면 LocalCut AI를 다시 실행합니다. **모델 · 업데이트**에서 small이 **준비됨**인지 확인하고 짧은 한국어 영상을 분석합니다. 기존 앱의 다운로드 버튼을 다시 누를 필요는 없습니다.
5. 실패하면 **model-repair-results/RESULT.txt** 내용을 채팅에 알려 주세요.

복구 도구는 모델 파일만 다루고 원본 영상·음성·대본·작업 기록을 읽거나 전송하지 않습니다. Hugging Face에서 무료 공개 모델 파일을 받으며 유료 API, 계정 생성, 프로그램 재설치가 필요 없습니다. 원본 모델과 고정 버전·체크섬은 기존 catalog를 유지합니다.

## 호환성 처리와 검증 범위

새 코드의 일반 모델 설치는 저장소에 게시된 TXT/JSON 형식을 그대로 사용합니다. 이미 설치된 0.1.0의 동결 엔진은 JSON 파일을 요구하므로 복구 도구만 TXT 어휘를 CTranslate2가 지원하는 JSON 문자열 배열로 변환합니다. 토큰 순서·공백·빈 항목을 그대로 보존하고 CTranslate2 텍스트 판독 방식과 동일하게 CRLF만 처리합니다. 모델 가중치·설정·tokenizer는 수정하지 않습니다. 변환 출처와 해시를 manifest에 기록합니다.

정상화된 파일을 임시 폴더에서 검증하고 **실제 CPU 모델·tokenizer 불러오기까지 성공한 뒤** 앱의 모델 폴더에 적용합니다. 성공 결과의 `nativeCpuLoadVerified`는 해당 PC에서 실제 가중치 로드가 통과했다는 뜻입니다. **실제 한국어 발화 인식 정확도나 자막 동기화 테스트가 완료됐다는 뜻은 아닙니다.**

클라우드 검증에서는 TXT/JSON 가져오기, 게시된 TXT를 선택하는 다운로드 경로, 캐시 경로 유지, 토큰 ID 보존, 이전 JSON-only 엔진과 manifest 호환, 네이티브 모델 검증 실패 시 기존 모델 보존, 복구 결과의 실패/성공 기록을 검사합니다. 다운로드 경로 테스트는 저장소 응답 대역을 사용합니다. 실제 모델 다운로드·CPU 로드 결과는 사용자의 PC에서 복구 도구를 실행한 뒤 별도로 확인해야 합니다.
