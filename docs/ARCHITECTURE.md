# 구조와 유지보수

## 프로세스와 저장

React renderer → 좁은 preload API → Electron main IPC → Python 단일 요청 프로세스 → FFmpeg. 웹 서버나 공개 포트를 사용하지 않습니다. 명령은 stdin JSON, 진행률·결과는 stdout NDJSON, 라이브러리 로그는 stderr입니다. 스크립트·셸 문자열 실행을 허용하지 않습니다.

`desktop/`는 한국어 UI와 OS 파일 선택/저장, `engine/`은 프로젝트·분석·편집 계획, `media/`는 FFmpeg, `subtitles/`는 자막과 시간 변환, `models/`는 동의 기반 다운로드·해시 관리, `updater/`는 업데이트 상태 전이를 담당합니다. `scripts/`에는 실제 빌드와 검증 스크립트가 있습니다.

작업은 schema 1 JSON입니다. 프로젝트 ID는 32자리 hex, 원본 경로는 생성할 때만 결정합니다. UI 수정 요청으로 원본·출력 경로를 바꿀 수 없습니다. 임시 파일 fsync 후 교체해 저장하고 이전 상태를 `previous.json`에 유지합니다. 알 수 없는 스키마 버전은 열지 않습니다. 향후 스키마 변경은 마이그레이션과 이전 파일 백업을 추가하고 테스트해야 합니다. UI 색상·출력 설정은 프로젝트마다 저장합니다. 업데이트 채널은 실행 중 선택으로 v0.1에서는 재실행 시 stable로 돌아옵니다.

## 분석·편집 알고리즘

1. FFprobe로 메타데이터·회전 확인. 파일 크기·수정 시각을 기록합니다. MP4/H.264/AAC·MP3 이외의 컨테이너·코덱은 로컬 H.264/AAC 호환 미리보기(최대 1280×720)를 만들고, 실제 분석·출력에는 항상 원본을 사용합니다.
2. FFmpeg로 초당 2개 160×90 프레임을 스트리밍 디코딩합니다. PySceneDetect ContentDetector로 장면 전환, 인접 회색 프레임 차로 움직임을 측정합니다.
3. FFmpeg silencedetect(-38 dB)와 faster-whisper에 포함된 Silero ONNX VAD로 침묵·발화를 확인합니다.
4. faster-whisper 한국어, beam=5, 단어 시간, 로컬 모델 경로, CPU int8 또는 CUDA float16으로 대본을 만듭니다. 추론 시 네트워크는 사용하지 않습니다.
5. 대본 구간과 VAD 음성 주변을 보호합니다. 긴 무음에서 보호 구간·장면 변화·움직임이 없는 경우만 삭제합니다. 화면이 변하면 보존 중인 제안으로 남깁니다.
6. 인접 문장의 문자열 유사도와 ‘아니/다시 말/정정’ 신호를 비교합니다. 명시적 재녹음+높은 일치도+높은 ASR 신뢰도 조건일 때만 자동 삭제하고 중요 표현은 보호합니다. 강조 반복과 불확실한 말실수는 검토 대상으로 둡니다.
7. 핵심어 빈도와 ‘핵심/중요/주의/반드시/결론’ 표현으로 점수를 계산합니다. 쇼츠는 최고 점수 문장 주변의 연속 구간을 문장 경계에서 제안합니다. 앞뒤 삭제는 사용자가 검토해 적용합니다. 영상 전체의 의미를 이해하는 생성형 모델이 아닙니다.
8. 원본·완전히 보존·삭제·일부 보존 대본을 비교합니다. 수동으로 중요한 대화를 삭제했으면 경고합니다.

설정은 `engine/styles.json`에 분리되어 있습니다. 최대 삭제 비율, 짧은 보존 구간과 컷 과다를 제한합니다. 빠른 모드도 불확실한 의미를 임의 삭제하지 않습니다. 시각 분석은 샘플링이므로 아주 짧은 전환이나 정지된 중요 장면을 놓칠 수 있습니다. 감정·객체·얼굴·장면의 의미 판단은 미구현입니다.

## 출력·자막

보존 구간을 프레임 기준으로 양자화 → FFmpeg trim/atrim → 8ms 오디오 경계 페이드 → concat → afftdn·loudnorm → 선택적 줌·비율 크롭·ASS 자막 → H.264/AAC 한 번 인코딩입니다. 효과·컷·자막의 정확성을 위해 재인코딩하며 무손실 스트림 복사는 별도 모드가 없습니다. 최대 300개 보존 구간을 지원합니다.

자막은 단어 타이밍·문장 길이·발화 공백으로 분할하고 삭제 후 시간축으로 이동합니다. 원본 문구를 자동 생성하지 않으며 공백·문장 부호만 정리합니다. ASS 제어문자는 이스케이프합니다. 수동 수정한 자막은 가장 많이 겹치는 보존 구간 한 곳에만 놓습니다. `report.json`에 실제 출력 구간과 대본 감사 결과를 기록합니다. 출력 길이 검사를 통과한 파일만 프로젝트 결과로 등록합니다.

## 기술 선택

| 선택 | 이유 | 비용·제한 |
|---|---|---|
| Electron/React/TypeScript | 한국어 UI, OS 통합, Windows NSIS와 updater | 설치 용량과 메모리가 네이티브 UI보다 큼 |
| Python + PyInstaller onedir | AI 생태계, 사용자의 Python 설치 불필요 | OS별 빌드 필요, 모델 제외해도 수백 MB 가능 |
| FFmpeg 별도 프로세스 | 재현 가능한 편집·오디오·코덱 | H.264와 자막 적용 시 인코딩 필요, GPL 구성 배포 의무 |
| faster-whisper small/tiny | 로컬 한국어, CPU int8, 무료 | 최초 모델 다운로드, tiny 정확도 제한, 실제 한국어 검증 필요 |
| Silero VAD (faster-whisper 내장) | 저비용 음성 보호 | 음악·잡음·감정의 의미 이해 불가 |
| PySceneDetect + 프레임 차 | CPU 장면 전환·움직임 | 화면 의미 이해·얼굴 추적 미지원 |
| JSON | 단일 PC 독립 저장, 파일 복구 용이 | 대규모 기록 검색·동시 편집에는 SQLite 전환 고려 |
| electron-updater/GitHub Releases | SHA-512, 다운로드 진행률, 버전 관리 | 저장소·릴리스 운영 필요, 서명·사설 배포는 관리자 설정 |

## 유지보수 방법

자막 스타일 추가는 `Settings` 타입/검증, UI, `subtitles/captions.py`를 함께 변경합니다. 편집 정확도 개선은 `planner.py`, `styles.json`과 의미 보존 회귀 테스트를 먼저 수정합니다. 효과 확장은 `media/render.py`에서 별도 필터 생성기로 분리할 수 있습니다. BGM·효과음·로컬 LLM은 현재 포함하지 않았습니다.

변경 후 관련 Python/Node 테스트, 타입 검사, 실제 FFmpeg 통합 테스트, Electron smoke를 실행합니다. 릴리스 전 Windows frozen 엔진과 설치본 smoke, 한국어 실제 발화·GPU·업데이트 E2E 수동 검증까지 통과해야 합니다. 이미 통과한 테스트를 새 변경 없이 반복 확장할 필요는 없습니다.
