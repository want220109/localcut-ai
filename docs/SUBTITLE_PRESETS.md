# 유튜브·인스타 자막 프리셋 — 0.2.0

## 제공 스타일

| 프리셋 | 글꼴 | 기준 크기 | 배치 |
|---|---|---:|---|
| 유튜브 롱폼 · 깔끔한 기본 | 나눔고딕 Bold | 48px | 흰색·검은 테두리, 하단 7.5% 여백 |
| 유튜브 롱폼 · 반투명 박스 | 나눔고딕 Bold | 46px | 흰색·반투명 어두운 박스, 하단 8% |
| 유튜브 쇼츠 · 또렷한 강조 | 나눔고딕 Bold | 76px | 흰색·두꺼운 테두리, 하단 23%·오른쪽 17% |
| 유튜브 쇼츠 · 옐로 타이틀 | Black Han Sans | 82px | 노란 제목체, 하단 24%·오른쪽 17% |
| 인스타 릴스 · 미니멀 | 나눔고딕 Bold | 64px | 흰색·얇은 테두리, 하단 25%·오른쪽 18% |
| 인스타 릴스 · 볼드 포인트 | Black Han Sans | 74px | 두꺼운 제목체·반투명 박스, 하단 25%·오른쪽 18% |

새 프리셋의 글자 크기는 **출력 영상의 짧은 변이 1080px일 때** 기준입니다. 예를 들어 쇼츠 1080×1920에서는 76px, 720×1280에서는 약 51px로 비례 조정합니다. 기존 작업은 이전의 ‘높이 1080px 기준’ 크기 계산과 스타일을 유지합니다.

여백은 플랫폼 버튼·설명 영역을 피하기 위한 보수적인 시작값이며 **유튜브/인스타 공식 안전 영역이나 모든 기기에서의 보장을 뜻하지 않습니다.** 업로드 미리보기에서 실제 UI와 겹치는지 확인하고 위치·여백을 조정하세요.

## 사용하는 방법

1. 영상을 불러오고 **자동 자막**을 켭니다.
2. **업로드용 자막 프리셋**에서 사용할 스타일을 선택합니다.
3. 글꼴·굵기·크기·색상·테두리·위치·위치 여백을 필요에 맞게 바꿉니다. ‘강조 단어’에 쉼표로 구분한 단어를 입력하면 실제 자막 안에서 일치한 부분만 강조합니다. 문구를 추가하거나 AI로 말을 만들어 넣지 않습니다.
4. 세로형 출력이 필요하면 **9:16 화면 비율 적용**을 직접 누릅니다. 프리셋 선택만으로 영상 비율·해상도·화질·줌을 바꾸지 않습니다. 비율 변경은 기존 중앙 크롭 동작을 사용하므로 피사체를 확인하세요.
5. **MP4 출력** 후 결과를 재생하고 **MP4 저장**합니다. 기존 자막에 스타일만 적용할 때는 음성 재분석이 필요 없습니다.

프리셋을 바꿔도 자막 문구·시간·수동 편집 구간은 유지됩니다. 새 음성 분석은 프리셋의 문장 길이 기준으로 자막을 분할합니다. 기존·수동 자막은 단어를 버리지 않고 두 줄 이내로 배치하며 필요하면 크기를 줄입니다. 그래도 들어가지 않는 매우 긴 문장은 출력 전에 오류로 안내합니다. 직접 넣은 줄바꿈은 시간축 변환과 SRT 저장에 보존합니다.

**폰트·색상 예시는 스타일 확인용**이며 실제 영상 위의 위치·크기는 MP4 출력에서 확인합니다. SRT에는 폰트·색상·강조가 들어가지 않고 텍스트·시간만 저장됩니다. 스타일은 MP4에 삽입하는 ASS 자막에 반영합니다.

## 비용·글꼴

나눔고딕 Regular/Bold와 Black Han Sans는 SIL Open Font License 1.1로 배포되는 원본 파일을 검증해 포함했습니다. 유튜브·인스타 상업 영상에도 사용할 수 있고 폰트 구입·유료 API·폰트 런타임 다운로드가 필요 없습니다. 맑은 고딕은 Windows 시스템 글꼴로 선택할 수 있으며 파일을 재배포하지 않습니다.

폰트 출처와 체크섬은 `assets/fonts/SOURCES.json`, 라이선스 전문은 같은 폴더의 `LICENSE-*.txt`에 있습니다. 글꼴 파일의 내용·이름 테이블은 수정하지 않았습니다. 동결 엔진과 UI에 포함하므로 사용자 PC에 별도로 폰트를 설치하지 않습니다.

## 기존 PC 업데이트

1. LocalCut AI를 정상 종료합니다.
2. 0.2.0 업데이트 ZIP의 **LocalCut-AI 안에 있는 전체 파일·폴더**를 이전에 테스트한 **기존 LocalCut-AI 폴더**에 복사하고 덮어씁니다. `assets`, `subtitles`, `desktop`, `engine`, `media`, `scripts`, `package.json`, `package-lock.json` 등 업데이트 파일을 모두 복사해야 합니다.
3. 기존 `.venv-win`, `node_modules`, `vendor`, 모델·작업 폴더는 삭제하지 않습니다.
4. 기존 폴더의 **UPDATE-SUBTITLE-STYLES.cmd**를 더블클릭합니다. 기존 의존성을 재사용해 UI·엔진을 빌드하고 설치본을 만들어 설치·테스트합니다. 모델을 다시 다운로드하거나 외부에 공개 배포하지 않습니다.
5. 끝나면 앱의 버전이 **0.2.0**인지 확인합니다. 오류가 나면 `windows-results/RESULT.txt` 내용을 채팅에 붙여 주세요.

처음 설치하는 PC는 `START-WINDOWS-TEST.cmd`를 사용합니다. **0.2.0 Windows 설치본은 이 클라우드에서 생성하지 않았습니다.** 이 패키지는 PC에서 설치본을 만드는 업데이트 소스·글꼴·실행기입니다. 클라우드 Linux에서 기능 검증을 완료한 뒤 사용자 Windows의 업데이트 결과를 별도로 확인해야 합니다.
