# 설치 및 사용

0.2.2의 최신 파일 저장과 편집 적용 요약은 [1차 업데이트 안내](UPDATE_PHASE1.md), 이후 개발 순서는 [단계별 계획](ROADMAP.md)을 참고하세요.

유튜브 롱폼·쇼츠·인스타 릴스용 폰트와 크기는 **0.2.0의 [자막 프리셋 안내](SUBTITLE_PRESETS.md)**를 참고하세요. 기존 작업의 문구·시간·편집 구간을 유지하면서 스타일을 적용하고 MP4만 다시 출력할 수 있습니다.

## Windows 설치 (릴리스가 만들어진 뒤)

1. 관리자가 제공한 GitHub Release 또는 사내 배포 위치에서 `LocalCut-AI-<버전>-x64-Setup.exe`를 받습니다.
2. 게시자와 다운로드 출처를 확인한 후 설치 마법사에서 경로와 바로가기를 선택합니다.
3. 시작 메뉴에서 **LocalCut AI**를 실행합니다. Python·FFmpeg는 설치본에 포함됩니다.
4. **모델 · 업데이트**에서 한국어 권장 `small`(약 490 MB) 또는 빠른 `tiny`(약 76 MB)를 선택합니다. ‘다운로드에 동의하고 설치’를 누르면 모델 파일만 받습니다. 영상은 전송하지 않습니다.
5. 인터넷을 사용할 수 없으면 신뢰할 수 있는 faster-whisper CTranslate2 모델 폴더를 ‘오프라인 폴더 가져오기’로 가져옵니다. `config.json`, `model.bin`, `tokenizer.json`과 어휘 파일(`vocabulary.txt` 또는 `vocabulary.json`)이 필요합니다. 모델 디렉터리의 코드를 실행하지 않습니다. 기존 0.1.0 설치본은 JSON만 처리하므로 [모델 다운로드 복구](MODEL_DOWNLOAD_REPAIR.md)를 먼저 참고하세요.

GitHub 공개 릴리스는 아직 없습니다. 사용자 PC의 실행 로그에서는 Windows 설치본 제작과 앱 화면 실행이 확인됐으며, 현재 실제 한국어 모델·영상 검증을 진행 중입니다.

## 편집

1. 영상을 선택하거나 빈 업로드 영역에 드래그합니다. 원본의 경로·크기·수정 시각을 저장하고 원본을 덮어쓰지 않습니다. AVI·MKV 등 브라우저 재생이 어려운 형식은 자동으로 호환 미리보기를 만듭니다. 이 과정은 영상 길이에 따라 시간이 걸리며 원본 화질로 출력할 때는 원래 파일을 사용합니다.
2. 기본 / 빠른 / 쇼츠·릴스를 선택합니다. 쇼츠는 9:16 중앙 크롭을 사용합니다. 사람을 자동 추적하지 않으므로 좌우 피사체가 잘리는지 확인하세요.
3. ‘AI 분석·편집점 생성’을 누릅니다. 음성이 있으면 모델 준비가 필수입니다. 모델 없이 무음 제거만 수행하고 AI 분석이 끝났다고 표시하지 않습니다.
4. 타임라인과 편집 구간에서 삭제 이유를 확인합니다. ‘보존 중’ 후보는 자동 삭제하지 않았습니다. 필요할 때 ‘삭제 적용’을 누릅니다. ‘복원’하면 원래 장면이 다시 보존됩니다.
5. 시작·종료 시간을 초 단위로 바꾸거나 직접 삭제 구간을 추가합니다. 전체 영상 삭제, 잘못된 시간과 범위는 거부됩니다.
6. 자막 수정 탭에서 문구·시간을 수정한 후 **자막 수정 저장**을 누릅니다. 입력만 한 자막은 자동 저장되지 않습니다. 시간 기준은 원본입니다. 출력 때 삭제 구간을 반영해 시간축을 바꿉니다.
7. 대본 비교에서 삭제된 문장과 일부만 남은 문장을 확인합니다. 중요 표현이 포함된 문장을 삭제했다면 경고를 확인합니다.
8. ‘MP4 출력’을 누르면 작업 폴더에 현재 편집 결과를 만듭니다. 원본·결과 미리보기의 시간을 독립적으로 움직여 비교합니다. ‘MP4 저장’ 또는 ‘출력된 SRT 저장’으로 저장할 때 출력본이 없거나 수정 전 결과라면 최신 편집으로 다시 출력한 뒤 복사합니다. 자막 입력은 먼저 ‘자막 수정 저장’으로 적용해야 합니다.

‘원본 유지’ 비율은 원본 가로·세로비를 유지합니다. 다른 비율은 중앙 크롭입니다. 720p/1080p는 가로형에서 높이 기준, 9:16에서는 짧은 변 기준입니다. 자막 크기는 1080 높이 기준으로 비례 조정합니다. 기본 자막은 Windows 맑은 고딕을 사용합니다.

## 자연어 수정

- ‘자막을 더 크게 해줘’ / ‘자막을 작게 해줘’
- ‘잘라낸 대화를 다시 살려줘’ → 모든 삭제 구간 복원
- ‘줌 효과를 줄여줘’ → 줌 끄기
- ‘편집을 조금 더 빠르게 해줘’ / ‘침묵을 조금 더 제거해줘’ → 빠른 모드 변경 후 재분석 안내

정해진 명령을 처리하는 무료 규칙 기능입니다. 자유로운 요구를 이해하는 대화형 언어 모델은 포함하지 않았습니다. 모드를 바꾼 뒤 재분석하면 편집점과 자막이 초기화되므로 확인창을 읽어 주세요. 이전 변경 되돌리기는 한 단계의 상태를 교환합니다.

## 저장 위치·성능·복구

- Windows 사용자 데이터: 보통 `%APPDATA%/LocalCut AI/workspace/` 아래 `jobs/`와 `models/`입니다. 설정은 작업 JSON에 저장됩니다.
- 작업 변경은 앱의 작업 폴더에 자동 저장됩니다. 최근 작업으로 다시 열 수 있습니다. 앱 업데이트는 이 폴더를 삭제하지 않습니다.
- 원본을 옮겼거나 덮어썼다면 원래 파일을 복원하거나 새 작업으로 가져옵니다. 버전 0.1에서는 원본 재연결 기능이 없습니다.
- 결과를 바꾼 뒤에는 ‘수정 후 다시 출력 필요’가 표시됩니다. 기존 결과는 이전 수정 시점의 영상입니다.
- CPU `int8`을 기본 지원합니다. RAM 8 GB 이상, 여유 공간 5 GB 이상을 권장하지만 실제 처리량은 PC·영상 길이·해상도에 따라 다릅니다. 오디오를 메모리에 디코딩하므로 매우 긴 영상은 높은 메모리를 사용합니다.
- CUDA를 사용할 수 있으면 GPU를 시도합니다. 필요한 CUDA/cuDNN이 없으면 CPU로 전환합니다. GPU 패키지는 설치본에 포함하지 않습니다. GPU 테스트는 별도 필요합니다.
- 인코딩 중 정상 종료는 막습니다. 현재 버전에는 작업 취소·중단 재개가 없습니다. 강제 종료했다면 앱 재실행 후 작업을 열고 다시 출력합니다. 불완전 파일은 최종 결과로 등록하지 않습니다.
- 한국어 음성인식의 오인식·띄어쓰기는 직접 수정할 수 있습니다. 자동 정리는 공백과 문장 부호에 한정되며 별도 맞춤법 모델은 없습니다.

## 업데이트

새 버전 발견 시 내용 확인 → 다운로드 → 작업 완료 후 ‘설치하고 재시작’을 선택합니다. 다운로드만 했다고 자동 설치하지 않습니다. 업데이트 실패 시 현재 버전을 계속 사용할 수 있으며 네트워크·디스크를 확인해 재시도합니다. 이전 안정 버전 복구는 관리자에게서 받은 설치 파일로 수동 진행합니다.

서명이 없는 시험 빌드는 Windows SmartScreen에서 ‘알 수 없는 게시자’ 경고를 표시할 수 있습니다. 경고를 무조건 우회하지 말고 관리자가 확인한 출처·SHA-256과 일치하는지 확인하세요. 정식 배포에는 관리자의 코드 서명 인증서가 권장됩니다. 프로그램 제거는 Windows 설정 → 설치된 앱에서 진행합니다. 작업 데이터는 보존되므로 삭제가 필요하면 사용자가 별도로 백업 후 지웁니다.
