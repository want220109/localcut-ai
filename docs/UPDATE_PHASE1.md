# 1차 업데이트 — 편집 구간 적용과 최신 파일 저장 (0.2.2)

## 바뀐 사용 흐름

1. 영상을 불러와 분석합니다. 저장 개선은 기존 작업에도 적용됩니다. 새로운 편집점 선정 기준은 다시 분석해야 반영되므로, 기존 자막·수동 편집을 유지하며 시험하려면 원본을 **새 작업으로 불러와 분석**하세요.
2. **편집 적용 요약**에서 원본/예상 결과 길이, 삭제 적용 수, 단축 시간, 검토 제안 수를 확인합니다.
3. `보존 중`인 침묵·발화 공백 등의 제안은 실제 영상을 확인한 뒤 **삭제 적용**을 누릅니다. 적용 전에는 길이가 줄지 않습니다. 잘못 적용했다면 복원할 수 있습니다.
4. **MP4 출력**을 누르면 현재 편집 결과를 미리 볼 수 있습니다. 이전 결과를 보고 있을 때는 `이전 출력 미리보기`로 표시합니다.
5. **MP4 저장**을 누르면 현재 편집과 출력본이 같은지 확인합니다. 출력본이 없거나 오래됐으면 최신 편집으로 먼저 출력한 뒤 저장 위치를 선택합니다. SRT·출력 보고서 저장에도 최신 출력 확인이 적용됩니다.

저장 대화상자를 열어 둔 동안에는 편집과 업데이트 설치를 막습니다. 저장을 취소하면 복사하지 않으며 원본 경로에는 저장할 수 없습니다. 현재 결과 길이와 이전 결과 길이를 구분해 표시합니다.

## 길이가 그대로인 경우

- **검토 제안이 보존 중:** 아직 삭제를 적용하지 않은 상태입니다. 후보와 앞뒤 장면을 확인하세요.
- **삭제 구간을 모두 복원함:** 원본 길이를 유지하는 것이 정상입니다.
- **충분한 근거를 가진 자동 삭제 구간이 없음:** 이유를 표시하고 원본을 보존합니다. 임의로 일정 비율을 잘라 길이를 맞추지 않습니다.
- **편집 모드만 바꿈:** 재분석해야 새 모드의 편집 기준이 반영됩니다. 재분석은 기존 자막/수동 편집을 바꿀 수 있어 확인 안내를 따르세요.

## 편집점 선정 보완

단어 시간 정보가 완전하고 신뢰할 수 있는 경우에는 문장 전체가 아닌 단어 주변을 보호해 발언 사이의 확인된 침묵을 찾습니다. VAD가 감지한 미인식 음성, 중요·저신뢰 문장과 불완전한 단어 정렬은 계속 보호합니다. 단어를 모두 살린 채 침묵만 제거한 경우 대본이 일부 삭제됐다고 잘못 표시하지 않습니다.

완전한 무음이 아니어도 VAD와 대본에서 발언 사이 공백을 찾으면 `발화 공백` 검토 후보로 제시할 수 있습니다. 배경음·음악·행동 장면이 있을 수 있어 자동 삭제하지 않습니다. 화면 움직임이나 장면 변화가 있는 무음도 계속 검토 대상으로 남깁니다.

이는 [5단계 계획](ROADMAP.md)의 1차 작업입니다. 대본 교정 보존, 여러 원본 재배치, 로컬 AI 이야기 구성, 고급 음향/화면 마무리가 모두 구현됐다는 의미는 아닙니다. 유료 API나 새 모델 다운로드는 추가하지 않았습니다.

## 확인 범위

Python 59개·Node 6개, Linux Electron·동결 엔진, [Windows 빌드·설치 및 설치된 앱 검증](https://github.com/want220109/localcut-ai/actions/runs/44032082532)이 통과했습니다. 이전 4초 출력 이후 삭제를 복원하고 저장했을 때 최신 6초 파일이 저장되는 것을 Windows에서도 확인했습니다. 테스트 영상과 대본 시간 데이터로 검증했으며 실제 한국어 발화 인식 정확도, 사용자 원본 두 건의 원인 확정, 사용자 PC 업그레이드와 인터넷 업데이트 설치는 별도 확인 항목입니다. 최신 Windows 실행 결과는 [STATUS](STATUS.md)에 기록합니다.
