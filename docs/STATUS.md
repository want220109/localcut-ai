## 0.3.5 — 여러 영상의 롱폼 구성 초안과 편집

영상 편집에서 저장된 교정 자막의 도입·마무리 표현과 클립 경계를 보고 도입·본론·마무리 구간을 제안합니다. 제안 단계에서 프로젝트와 출력은 보존합니다. 6초 이내 구간 미리보기, 순서 변경, 포함 여부, 확정 구성을 다시 여는 기능을 제공합니다. 적용한 AI 컷 위에서 확정 구간을 합치며 예상 길이, 실제 MP4와 자막 시점을 같은 프레임 기준으로 계산합니다.

Python 86개, Node 테스트, TypeScript 빌드, 실제 Linux Electron, 동결 엔진 검사와 [Linux CI](https://github.com/want220109/localcut-ai/actions/runs/45568104259)가 통과했습니다. 교정 자막에 따른 배치 제안, 자막 없는 클립의 기본 경계, 구간별 미리보기, 검토 중 원본과 프로젝트 보존, 확정한 순서 및 제외 상태 재열기를 확인했습니다. 실제 MP4의 프레임과 SRT를 검사했고, 같은 클립 안의 구간을 재배치한 예제에서도 기존 컷과 자막이 반영됐습니다. 이번 구성 검사는 이미 저장한 자막을 사용했으며 실제 한국어 음성 모델과 CUDA 검사는 별도입니다.

[Windows 설치 검사](https://github.com/want220109/localcut-ai/actions/runs/45568104435)가 통과했습니다. Windows에 설치한 앱의 번들 엔진으로 여러 클립의 구성 초안을 만들고, 구간을 미리 본 뒤 순서와 포함 여부를 바꿔 MP4로 저장했습니다. Linux 앱의 최소 창 크기에서 구간과 조작 버튼이 가려지지 않는 것도 확인했습니다.

[Windows 업그레이드 검사](https://github.com/want220109/localcut-ai/actions/runs/45569018356)에서 공개 v0.3.4 설치본을 테스트 주소로 v0.3.5로 올렸습니다. 다운로드와 손상된 설치본 거부, NSIS 설치, 자동 재시작, 모델 폴더의 검사 파일과 기존 작업·자막·컷·설정 유지, MP4 출력을 확인했습니다. 공개 업데이트 주소의 검사는 게시 뒤에 실행할 수 있습니다.

Windows 설치본, 업데이트 목록, 대응 소스를 배포 초안에 올리고 파일 크기와 체크섬을 확인했습니다. [v0.3.5 배포 초안](https://github.com/want220109/localcut-ai/releases/tag/untagged-9cd27065eae6608c7629)

영상 편집에서 포함한 클립의 대본, 음성·침묵 감지와 장면 움직임을 근거로 편집점을 찾습니다. 근거가 충분한 침묵은 자동 적용하고 반복, 말실수, 움직임이 있는 구간은 검토 후보로 보존합니다. 적용 여부를 바꾸거나 연결부를 미리 볼 수 있습니다. 적용한 컷의 보존 프레임을 예상 길이, 영상·오디오, 자막 시점과 클립 연결부에 반영합니다.

[Windows 업그레이드 검사](https://github.com/want220109/localcut-ai/actions/runs/45561156555)에서 기존 공개 v0.3.3 설치본을 테스트 주소로 v0.3.4로 올렸습니다. 다운로드와 손상된 설치본 거부, NSIS 설치, 자동 재시작, 모델 폴더의 검사 파일과 작업·자막·컷·설정 유지, MP4 출력을 확인했습니다. 공개 업데이트 주소의 검사는 게시 뒤에 실행할 수 있습니다.

## 0.2.9 — 대본 컷 편집과 연결부 재생

대본에서 선택한 한 줄 또는 여러 줄의 원본 영상 구간을 제외하거나 복원합니다. 겹친 컷은 선택한 시간만 복원하며, 기존 자막 문구를 보존합니다. 컷 적용 후 예상 결과 길이를 갱신합니다. 연결부 미리보기는 보존된 영상과 소리를 컷 앞뒤 각각 최대 3초씩 연결하여 PC에서 재생합니다.

초기 0.2.0 검증은 **클라우드 Linux/Xvfb**에서 수행했고, 이후 위 GitHub Windows run에서 새 설치본 생성·설치·설치된 앱 검증까지 통과했습니다. 사용자의 실제 PC에서 기존 버전 업그레이드 결과를 확인하는 단계는 남아 있습니다. 글꼴·여백은 플랫폼용 권장 시작값으로 공식 안전 영역 보장이 아닙니다. 자세한 내용은 [자막 프리셋](SUBTITLE_PRESETS.md)을 참고하세요.

### 모델 다운로드 오류와 복구 준비

사용자가 제공한 Windows 앱 화면에서 `small` 모델의 고정 버전 `vocabulary.json`이 404로 실패한 것을 확인했습니다. 사용자 PC에서는 모델 호스트에 접속했으며 파일 이름을 JSON으로 가정한 구현 오류입니다. 모델의 게시 파일 목록을 확인해 TXT/JSON을 선택하도록 수정하고, 기존 설치본을 재빌드하지 않는 모델 복구 도구를 추가했습니다. CTranslate2의 공개 소스에서 TXT/JSON 어휘 판독 방식을 확인해 토큰 ID를 보존하는 JSON 호환 변환을 구현했습니다.

수정 후 Python 테스트 34개와 Linux 동결 엔진 빌드·실행 검증이 통과했습니다. 이 중 온라인 다운로드 선택과 CPU 실패 처리 테스트는 대역을 사용했으며 실제 Whisper 가중치로 인식한 결과가 아닙니다.

복구 도구는 기존 다운로드 캐시를 재사용하고 앱을 종료한 상태에서 모델만 준비합니다. 실제 CPU 가중치 로드가 성공해야 복구 성공을 기록합니다. 클라우드에서는 형식 선택·해시·호환 변환·실패 보존·결과 보고를 회귀 검증하며, 실제 사용자 PC의 모델 다운로드/가중치 로드/한국어 발화 인식 결과는 아직 받지 않았습니다. 자세한 실행 방법은 [모델 다운로드 복구](MODEL_DOWNLOAD_REPAIR.md)를 참고하세요.

### 사용자 Windows 실행 로그로 확인한 결과

이후 사용자가 보낸 Windows 실행 로그에서 **Python 22개 통과, Node 3개 통과, 실제 Electron 편집·재실행 통과, Windows PyInstaller 동결 엔진 검증 통과, NSIS 설치 파일 및 blockmap 생성**을 확인했습니다. Python 3.12.10 x64, Node 24.22.0, electron-builder 로그의 Windows 버전은 10.0.26300입니다. 이 결과는 사용자 PC 로그를 읽고 확인했으며 클라우드에서 Windows를 직접 조작한 결과는 아닙니다.

빌드 후 실행기의 `Get-Content`가 한국어 UTF-8 `package.json`을 ANSI로 읽어 `ConvertFrom-Json` 오류가 났습니다. 따라서 **설치 실행과 설치된 앱의 자동 테스트는 아직 미완료**이며 실제 음성·온라인 업데이트도 미검증입니다. 설치본은 사용자 PC의 `release/LocalCut-AI-0.1.0-x64-Setup.exe`에 생성된 로그가 있고 클라우드 작업 공간으로 전송되지는 않았습니다.

UTF-8 명시와 설치 단계 재개 실행기를 추가했습니다. 비 BOM 한국어 UTF-8 JSON, 이미 생성한 설치본 탐색, 설치본 누락 시 중단을 PowerShell 회귀 검증에 추가해 Linux PowerShell에서 통과했습니다. 수정된 실행기의 실제 Windows 재개 결과는 아직 받지 않았습니다. 개인 경로가 포함된 원본 로그는 소스 저장소에 넣지 않았습니다.

### Windows 실행 이전의 준비 기록

사용자의 Windows 10/11 PC 접속을 확인했습니다. 이 채팅의 도구는 여전히 클라우드 Linux에 연결되어 있으며 사용자 PC의 Windows 화면·터미널을 직접 제어할 수 없습니다. 따라서 Windows 설치·실행 테스트가 끝났다고 기록하지 않습니다.

GitHub 없이 PC에서 실행하는 `START-WINDOWS-TEST.cmd`와 `scripts/windows-local-test.ps1`을 추가했습니다. 무료 도구가 없으면 동의 후 설치 → 프로젝트 의존성 → 소스 앱 테스트 → Windows 엔진 동결 → 설치 파일 생성 → 사용자 계정 설치 → 설치된 앱 테스트를 수행하도록 준비했습니다. 모델 다운로드는 별도 사용자 동의이며 온라인 배포는 수행하지 않습니다.

Microsoft 공식 PowerShell 7.7.0 배포 파일의 SHA-256을 확인한 후 Linux에서 실행기 문법, 하위 프로세스 0/7 종료 코드 처리, 실행 파일 누락 거부, 실패 결과 파일 기록을 실제 검증했습니다. **이 결과는 Windows PowerShell 5.1에서 설치·빌드가 성공했다는 뜻이 아닙니다.** Windows CI에도 같은 실행기 검사 단계를 추가했으나 원격 CI는 미실행입니다.

PC 실행 방법은 [Windows 빠른 시작](WINDOWS_QUICKSTART.md)에 있습니다. 아래의 2026-11-16 검증 기록은 이전 결과이며 새 Windows 결과로 대체하지 않았습니다. 실제 PC 결과는 사용자가 실행한 뒤 `windows-results/RESULT.txt`와 JSON에 기록됩니다.

**LocalCut AI v0.1.0의 실행 가능한 1차 소스를 구현했습니다. 완성된 정식 Windows 배포판이라고 보고하지 않습니다.** 현재 Cloud는 Linux이며 Windows 설치본과 실제 한국어 음성 추론·온라인 업데이트는 아직 검증하지 못했습니다.

## 스킬·모델·설치·비용
