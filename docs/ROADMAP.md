# 무료 로컬 롱폼 편집 단계별 계획

모든 단계는 유료 API·구독·별도 서버 없이 PC에서 처리하는 것을 기준으로 합니다. 원본과 기존 작업·모델을 보존하고, 확실하지 않은 삭제는 검토 제안으로 남깁니다. 아래 후속 단계는 계획이며 현재 구현 완료 기능으로 표시하지 않습니다.

## 1차 — 편집 적용과 저장 신뢰성 (0.2.2)

- 삭제 구간·자막 변경 후 저장할 때 최신 편집을 먼저 출력하고 저장합니다. 이전 출력 파일을 저장하지 않도록 main 프로세스에서 revision을 검사합니다.
- 저장 대화상자와 복사 완료까지 작업 잠금을 유지해 편집·업데이트 설치와의 경합을 막습니다. 원본 덮어쓰기와 잘못된 내보내기 형식도 차단합니다.
- 원본 길이, 예상 결과 길이, 중복을 제외한 삭제 시간, 적용 수와 보존 중인 검토 제안을 표시합니다. 이전 출력 미리보기와 현재 결과를 구분합니다.
- ASR 단어 정보가 완전하고 신뢰할 수 있으면 단어별 보호 구간을 사용합니다. VAD가 감지한 미인식 음성과 중요·저신뢰 문장은 계속 보존합니다.
- 배경음 때문에 완전한 무음으로 감지되지 않은 발언 사이 공백도 검토 후보로 제안합니다. 영상 도입/마무리와 음악·행동 장면을 VAD만으로 자동 삭제하지 않습니다.
- 삭제 비율 계산에서 겹친 구간을 중복 합산하거나 보류한 후보가 다음 후보의 한도를 소모하지 않도록 합니다.

완료 기준: 최신 파일 저장, 실제 단축 길이, 검토 후보 적용 전후 차이, 자막 시간, 원본 보존, 저장 취소와 동시 수정 차단을 실제 MP4와 앱에서 검증합니다.

## 2차 — 대본 검토와 영상 구간 연결

- 원본 STT 대본과 사용자가 교정한 문구를 구분해 보존합니다.
- 문장 클릭 재생, 인식 신뢰도가 낮은 부분 확인, 검색, 보존 표시를 제공합니다.
- 글자 교정과 영상 구간 삭제를 서로 다른 조작으로 표시합니다. 글자 수정이 음성을 바꾸지는 않습니다.
- 다시 구성하거나 자막 시간을 맞출 때 사용자 교정이 사라지지 않게 합니다.

완료 기준: 수정·재시작·편집 재계산 후에도 대본 교정과 원본 시간 연결이 유지됩니다.

## 3차 — 여러 원본과 구성 재배치·초벌 미리보기

- 여러 원본 파일의 구간을 선택해 순서를 바꾸는 편집 목록을 도입합니다.
- 원본 시간과 편집 후 시간을 함께 표시하고 구성 카드 이동·제외·복원을 지원합니다.
- 구간별·연결부·전체 초벌 미리보기를 제공하고 재배치에 맞춰 자막 시간을 매핑합니다.
- 검토용 미리보기와 최종 출력용 원본을 구분합니다.

완료 기준: 서로 다른 원본의 순서를 바꾼 결과, 화면·음성·자막과 최종 MP4의 순서가 일치합니다.

## 4차 — 무료 로컬 AI 구성 제안

- PC 사양과 배포 라이선스를 확인해 무료 로컬 언어 모델을 선정합니다. 모델 다운로드와 디스크 사용은 별도 안내합니다.
- 사용자가 정한 목적·목표 길이·보존 내용과 교정된 대본을 근거로 구성안을 제안합니다.
- 실제 원본 구간과 선정 이유를 제시하고, 원본에 없는 발언이나 잘못된 시간을 편집안으로 실행하지 않습니다.
- 도입·본론·마무리 또는 시간순 구성 등을 검토하고 추가 요청을 반영합니다. 모델 없이도 수동 구성은 가능합니다.

완료 기준: 구성안의 모든 구간이 실제 원본과 연결되고 사용자가 검토·수정·되돌릴 수 있습니다. 모델 성능과 처리 속도는 별도로 평가합니다.

## 5차 — 음향·화면·최종 자막 마무리

- 기본 음량 균일화·잡음 완화와 사용자가 추가한 음악의 음량 조절을 제공합니다.
- 기본 밝기·색상 보정, 사용자 보조 영상/사진 삽입, 제목 화면을 지원합니다.
- 확정된 편집 순서에 맞춰 최종 자막 시간·줄바꿈·스타일을 검수합니다.
- 최종 검수 후 원본 기반 MP4·SRT·작업 파일을 저장하고 길이·싱크·출력 설정을 확인합니다.

고급 생성형 영상, 섞인 음악과 음성의 완벽한 분리, 검수 없는 전문가 수준의 자동 완성은 초기 목표에 포함하지 않습니다.

## 배포 상태의 구분

소스 반영, Windows 설치본 빌드/테스트, 공개 Release 게시, 실제 사용자 PC의 인터넷 업데이트를 각각 기록합니다. Actions artifact 생성만으로 앱 업데이트 완료를 선언하지 않습니다. 공개 게시 절차는 [RELEASE](RELEASE.md)를 따릅니다.
